A single one-star review of the Moon, 120 characters at most: a rating, a
grievance, and a reason the Moon earned its single star.

## Run it

```sh
python3 main.py
```

Writes the review to `entry.txt` in the output directory
(`MAKEFUN_OUTPUT_DIR`, default `/output`) and prints it to stdout.
